# RADEST / KINDRA IP PROVENANCE & PRESERVATION PROTOCOL
Owner / IP custodian: ERIC DANIEL MALLEY

Treat material code, architecture, algorithms, workflows, documentation, UI/UX, inventions, improvements, and artifacts as potentially proprietary until reviewed. Preserve originals before changes; assign stable Asset IDs; record source/path, version, relationships, SHA-256 and applicable timestamps. Maintain SOURCE -> ORIGINAL -> VERSION -> CHANGE -> TEST -> DEPLOYMENT -> VERIFICATION. Evaluate significant work for patent, copyright, trademark, trade-secret, proprietary-method and reusable-infrastructure significance. Never commit secrets or sensitive PII. Use secret management and redaction. Statuses: VERIFIED, PARTIALLY VERIFIED, CONFIGURED BUT UNVERIFIED, NOT_CONFIGURED, NOT_VERIFIED, ACCESS_BLOCKED, CONFLICTING_EVIDENCE. Watermarks may contain project/asset ID, version, hash and preservation timestamp but never secrets. Git is one evidence layer, not the only backup. Never claim government filing, registration, certification or legal status without authoritative verification. This is an internal provenance procedure, not a legal registration.
